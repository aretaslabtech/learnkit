# Directivas permanentes — Proyecto Inglés (EOI)

Estas directivas regulan la gestión del conocimiento, la documentación persistente y el alcance documental de este proyecto. Complementan la guía metodológica del proyecto y no la sustituyen.

## 1. Alcance del proyecto

Este proyecto corresponde exclusivamente a las clases de inglés de la **EOI**.

El repositorio documental de este proyecto no debe mezclar contenido perteneciente a otros proyectos, incluyendo **Inglés Personal**, **Assimil** u otros repositorios, salvo petición expresa del usuario.

Si se detecta material que parece pertenecer a otro proyecto, no debe utilizarse ni moverse automáticamente. Debe respetarse el aislamiento entre proyectos.

## 2. Repositorio documental canónico

Este proyecto dispone de una carpeta propia de Google Drive añadida a las fuentes del proyecto:

**Proyecto - Inglés - Clases**  
https://drive.google.com/drive/folders/1gTRGm8WMaPW_TrQVR61uXS9u3Y_ei_6m

Esta carpeta constituye el repositorio canónico de los documentos y del conocimiento persistente generado por este proyecto.

Google Drive es el espacio de persistencia del conocimiento del proyecto.

Las conversaciones son el espacio de trabajo, razonamiento e interacción.

No toda la conversación debe convertirse en documentación. Se conservará únicamente la información relevante para el funcionamiento futuro del proyecto.

## 3. Uso del repositorio

Cuando una tarea dependa de información trabajada anteriormente:

1. Consultar los documentos relevantes existentes en la carpeta del proyecto.
2. Recuperar desde ellos el contexto y el estado necesario antes de proceder.
3. No depender exclusivamente del historial de conversaciones cuando exista información persistente en los documentos.
4. Si existe una diferencia entre información antigua de una conversación y la versión actual de un documento, utilizar como referencia el documento vigente, salvo que el usuario indique lo contrario.
5. Consultar primero el índice del repositorio cuando sea necesario localizar documentación o comprender la estructura disponible.
6. Después de consultar el índice, acceder siempre al documento fuente correspondiente; el índice sirve para orientarse, no sustituye al contenido de los documentos.

## 4. Documentos normativos del proyecto

Dentro de `00_Contexto_y_Guia` se mantienen los documentos de referencia general del proyecto.

### `Guia_maestra_Proyecto_Clases_de_Ingles.md`

Es el documento metodológico principal del proyecto.

Define, entre otros aspectos:

- cómo procesar el material de las clases;
- cómo crear resúmenes y mapas de estudio;
- cómo separar y organizar vocabulario;
- el uso de British English como referencia;
- los criterios de pronunciación e IPA;
- la metodología para tarjetas Anki;
- los criterios para imágenes y audio;
- el control de calidad de los materiales generados.

Cuando una tarea de aprendizaje dependa de estos criterios, consultar esta guía antes de proceder.

### `Indice_del_repositorio_EOI`

Es el punto de entrada documental del repositorio.

Debe describir:

- la estructura actual de carpetas;
- los principales documentos persistentes;
- la función de cada área relevante;
- el alcance documental del proyecto.

El índice no debe convertirse en una copia del contenido de los documentos.

## 5. Mantenimiento documental

Cuando durante el trabajo aparezca información que deba conservarse para futuras sesiones:

1. Determinar primero si corresponde a un documento existente.
2. Leer el documento antes de modificarlo.
3. Actualizarlo cuando sea posible en lugar de crear otro documento con información duplicada.
4. Crear nuevos documentos o subcarpetas únicamente cuando sean necesarios para mantener una organización clara.
5. Evitar copias, duplicados y versiones paralelas innecesarias.
6. Mantener nombres de archivos y estructura estables y descriptivos.
7. Organizar la información de modo que pueda comprenderse en futuros chats sin depender de la conversación original.
8. Preferir documentos vivos y actualizados frente a sucesivas versiones fechadas, salvo que exista una razón explícita para conservar versiones históricas.

## 6. Mantenimiento del índice

Mantener actualizado `00_Contexto_y_Guia/Indice_del_repositorio_EOI` cuando ocurra alguno de estos cambios:

- se cree o elimine una carpeta relevante;
- se cree, elimine, renombre o sustituya un documento persistente importante;
- cambie la función de una carpeta;
- aparezca un nuevo documento que deba utilizarse habitualmente como fuente del proyecto;
- cambie el alcance o la organización documental general del proyecto.

No es necesario actualizar el índice por cada audio individual, imagen, exportación de Anki, archivo temporal o material aislado de una clase, salvo que ese elemento pase a convertirse en una fuente persistente de referencia.

El índice debe reflejar el **estado actual** del repositorio y no mantener un historial de cambios.

## 7. Separación entre conversación y conocimiento persistente

Las conversaciones se utilizarán para:

- trabajar;
- analizar;
- decidir;
- resolver dudas;
- procesar materiales;
- definir cambios.

Google Drive se utilizará para:

- conservar conocimiento que deba sobrevivir a futuros chats;
- mantener documentos vivos;
- almacenar resultados consolidados;
- servir de fuente de contexto para nuevas conversaciones;
- permitir la reutilización posterior desde otras herramientas.

No se debe volcar automáticamente todo lo conversado a Drive.

## 8. Aislamiento del proyecto

Utilizar como repositorio documental únicamente la carpeta de Drive asociada a este proyecto.

No consultar, modificar ni utilizar carpetas pertenecientes a otros proyectos salvo petición expresa del usuario.

En particular:

- no utilizar material de `Inglés Personal`;
- no utilizar material de Assimil;
- no mezclar recursos de otros proyectos con EOI;
- no mover contenido hacia o desde otros proyectos sin autorización explícita.

## 10. Criterio de ubicación

### `00_Contexto_y_Guia`

Documentos que explican cómo funciona el proyecto y qué criterios deben seguirse.

### `01_Clases/00_Pendiente_de_procesar`

Material bruto de clases que todavía no haya sido consolidado.

### `01_Clases/01_Clases_procesadas`

Resultados consolidados de las clases: resúmenes, esquemas, vocabulario y otros documentos de estudio finalizados.

### `02_Anki`

Recursos y entregables relacionados con Anki:

- datos y exportaciones;
- imágenes;
- audio;
- plantillas.

### `03_Recursos_de_referencia`

Materiales de apoyo que pertenecen específicamente al proyecto EOI y que puedan ser reutilizados en distintas clases.

## 11. Prioridad de las directivas

La estructura documental debe adaptarse a las directivas y metodología existentes del proyecto.

Estas reglas regulan la recuperación, conservación y mantenimiento del conocimiento. No sustituyen ni redefinen la metodología pedagógica descrita en la guía maestra.

En caso de duda:

1. respetar el alcance EOI;
2. consultar el índice;
3. consultar el documento fuente relevante;
4. utilizar la versión vigente del documento;
5. actualizar el documento existente antes de crear uno nuevo;
6. mantener aislados los demás proyectos.
